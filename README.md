# 💰 Loaner

**Loaner** is a web-based application designed to efficiently manage the loaning process of assets within an organization.  
It streamlines **asset tracking**, **loan requests**, **approval workflows**, and **return monitoring**, ensuring accountability and optimal resource utilization.

---

## 🚀 Features

- 🗂️ **Asset Management** — Track all available assets including type, condition, and location
- 📝 **Loan Requests** — Users can request items to borrow with specified duration
- ✅ **Approval Workflow** — Admins can approve or deny requests based on availability and policies
- 🔄 **Return Tracking** — Monitor the return status of loaned items to prevent mismanagement
- 🖥️ **Web Interface** — Responsive frontend built with HTML, CSS, and JavaScript
- ⚙️ **Backend Logic** — Python backend handles business logic and database interactions
- 💾 **Database Integration** — Structured storage for assets and loan history
