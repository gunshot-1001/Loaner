🏦 Loaner

Loaner is a web-based application that streamlines the management of asset loans within an organization.
It allows users to request, track, and return assets efficiently, while providing admins with a full overview of approvals, availability, and asset status.

🚀 Features

📦 Asset Management — Track all assets with details like type, condition, and location

📝 Loan Requests — Users can request assets and specify loan duration

✅ Approval Workflow — Admins can approve or reject requests based on availability

⏱️ Return Tracking — Monitor the return status to prevent lost or delayed items

🖥️ Web Interface — Frontend built with HTML, CSS, JavaScript for responsive interaction

⚙️ Backend Logic — Python handles business logic and database integration

💾 Database Support — Stores asset and loan information securely

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Python

Database: Structured SQL or NoSQL database

Version Control: Git & GitHub
